ufunc function ufunc is short for universal function, and it's a function that performs operations on every element of an array. Many of NumPy's ufunc functions are implemented in C, so they operate very fast. &gt; x = np.linspace(0, 2*np.pi, 10) &gt; y = np.sin(x) &gt; y array([0.00000000e+00, 6.42787610e-01, 9.84807753e-01, ....., 2.44929360 e-16]) Note that for ndarray of the same length, np.sin () is faster than math.sin () But for a single value, math.sin () is faster.
