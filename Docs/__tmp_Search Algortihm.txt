4.2.6 Breadth-first search The basic idea: 1. Start node expansion from the initial node S 0, check whether the first child node of S 0 is the target node, if it is not the target node, then expand the node; 2. Then investigate whether the second child node of S 0 is the target node; if not, expand it; 3. After inspecting and expanding all the child nodes of S 0, then inspecting and expanding the child nodes of all the child nodes of S 0 respectively, searching downwards until the target state of S g is found. 4. Do not process the nodes of layer n+1 until all the nodes of layer n are investigated and expanded. style.visibility style.visibility style.visibility style.visibility

4.2.5 Depth-first search The basic idea (search and backtracking alternate) : 1. Start from the initial node S0 to expand the node, and check whether the last 1 child node of S0 is the target node. 2. If it is not the target node, expand the node; Then investigate the last 1 child node in its expansion node, if it is not the target node, expand it, and continue to expand down. 3. When it is found that the node itself cannot be expanded, expand one of its sibling nodes; 4. If all sibling nodes cannot be expanded, their parent node is found and sibling nodes of the parent node are expanded; And so on until the target state GS is found. style.visibility style.visibility style.visibility style.visibility
